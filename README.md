# 프나 컨텐츠 목록

프로미스나인 영상 캘린더(공개 구글 캘린더 `f9_video_calendar`)에서 오프라인 일정을 뺀 컨텐츠를 날짜순으로 모아 보는 페이지입니다.

캘린더는 2022년부터라서, 그 이전 컨텐츠(2017 아이돌학교~2021)와 모든 해의 TV·라디오 출연은 `archive/archive.json`에서 합칩니다. TV·라디오 출연은 다시보기 링크가 없어도 **방송** 항목으로 목록에 올라갑니다.

- 유튜브·위버스·인스타·틱톡·네이버·X·프롬 링크를 플랫폼, 멤버(생일순), 연도, 검색어로 거를 수 있습니다.
- 영상마다 **✓**로 본 것을 표시합니다. 열어 본 영상은 자동으로 표시됩니다. 기록은 각자의 브라우저에 저장되며, 페이지 위의 **다른 기기로 옮기기**로 복사해 다른 기기에 합칠 수 있습니다.
- 프롬 라이브 링크는 PC에서 실행 중인 프롬 PC 다시보기(`http://127.0.0.1:12212/`)로 열립니다. 플레이어가 없으면 옆의 **프롬 앱** 링크를 쓰면 됩니다.

## 자동 갱신

`.github/workflows/update.yml`이 매일 03:00(한국 시간)에 실행됩니다.

1. `python build.py`로 캘린더를 받아 `site/index.html`을 만듭니다. 외부 패키지는 필요 없습니다.
2. 내용이 바뀐 날에는 `.cache/`(프롬 짧은 링크 캐시, 썸네일, 마지막 갱신 정보)를 커밋합니다. 이 커밋 덕분에 GitHub의 예약 실행이 60일 비활성으로 멈추지 않습니다.
3. `site/`를 GitHub Pages에 배포합니다.

Actions 탭의 **Run workflow**로 바로 갱신할 수도 있습니다. GitHub의 예약 실행은 몇 분에서 수십 분 늦게 시작될 수 있습니다.

## 2022년 이전·방송 출연 목록 (archive)

`python archive/collect.py`가 아래에서 모아 `archive/archive.json`을 만듭니다. 매일 갱신되지는 않으니, 가끔 직접 실행해 결과를 커밋하면 됩니다.

- 나무위키 `프로미스나인/…` 하위 문서: TV 방송, 라디오, 네이버 나우, 음악 방송, V LIVE, 라이브 방송, 콘텐츠, 유튜브, 활동
- [프롬피디아](https://www.fromispedia.com/): 위에 없는 유튜브·위버스 링크 보충 (구글 드라이브 등 팬 업로드 링크는 넣지 않음)
- 공식 유튜브 채널: 위 두 곳과 캘린더에 없는 영상 (`yt-dlp`가 있으면 목록·날짜를 받음)

받은 원본은 `archive/raw/`에 캐시됩니다(저장소에는 안 올림). 새로 받으려면 그 파일을 지우고 다시 실행하세요. 캘린더 기간(2022~)의 방송 출연은 앞뒤 3일 안에 캘린더에 같은 프로그램이 있으면 빌드할 때 빠집니다.

## 썸네일

유튜브는 유튜브 썸네일을 바로 쓰고, 위버스·인스타·틱톡·네이버·X 등은 빌드할 때 대표 이미지를 받아 240×135로 줄여 `.cache/thumbs/`에 저장합니다(Pillow 필요, 저장소에 함께 커밋). 못 받은 링크는 30일 뒤 다시 시도합니다.

## 직접 만들기

```bash
pip install pillow
python build.py
```

만든 `site/index.html`을 브라우저로 열면 됩니다.
